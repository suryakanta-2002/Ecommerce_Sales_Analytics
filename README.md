# 🛒 E-Commerce Sales Analytics

A full-stack E-Commerce web application built with Python and Django, featuring online shopping, REST APIs, payment processing, MongoDB activity tracking, and sales analytics.

## 🚀 Features

- User Registration & Login
- Admin & Customer Role-Based Access
- Product Search, Filtering & Sorting
- Product Pagination
- Shopping Cart Management
- Wishlist
- Product Reviews
- Checkout & Order Management
- Order Cancellation
- COD & UPI Payment
- Automatic Stock Management
- Sales Analytics Dashboard
- Category-Wise Sales Analysis
- Top-Selling Product Analysis
- Sales Charts using Matplotlib
- REST APIs
- JWT Authentication
- MongoDB User Activity Tracking

## 📊 Sales Analytics

- Total Revenue
- Total Orders
- Total Items Sold
- Average Order Value
- Top-Selling Products
- Category-Wise Sales
- Sales Statistics
- Product Sales Visualization

## 🔌 REST API

The application provides APIs for:

- Products
- Cart
- Wishlist
- Orders
- Order Items
- Payments

Authentication is implemented using JWT and Session Authentication.

## 🍃 MongoDB

MongoDB is used to track user activities such as:

- Product Views
- Product Searches
- Wishlist Activities
- Activity Timestamps

## 🎯 Project Objective

The goal of this project is to build a real-world E-Commerce platform while implementing Full-Stack Development, REST APIs, Authentication, Database Management, Data Analytics, Data Visualization, and NoSQL Integration.
